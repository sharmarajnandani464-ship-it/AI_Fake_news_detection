AI Fake News Detection System

About the Project

The AI Fake News Detection System is a machine learning based web application designed to identify whether a given news article is likely to be real or fake.

The system uses Natural Language Processing (NLP), TF-IDF text vectorization, and Logistic Regression to analyze the provided news content and generate a prediction.

How It Works

The user enters a news article into the system. The text is converted into numerical features using TF-IDF, and the trained machine learning model analyzes these features to classify the news as either REAL NEWS or FAKE NEWS.

Technologies Used

• Python

• Machine Learning
• Natural Language Processing
• TF-IDF Vectorization
